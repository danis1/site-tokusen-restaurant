# 🌐 Site Tokusen

Aplicação web desenvolvida como projeto prático para a disciplina de **Desenvolvimento Web II** no curso de **Desenvolvimento de Software Multiplataforma (DSM)** da **FATEC Praia Grande**.

O **Tokusen** é uma plataforma focada na experiência de pedidos para culinária japonesa gourmet, oferecendo navegação intuitiva, catálogo de itens e gerenciamento dinâmico de carrinho de compras.

### ✨ Funcionalidades Principais

| Ícone | Funcionalidade | Descrição |
| :---: | :--- | :--- |
| 📱 | **Interface Responsiva** | Layout moderno adaptável para dispositivos móveis, tablets e computadores. |
| 🔐 | **Autenticação de Usuário** | Tela de login integrada para controle e acesso à área de pedidos. |
| 🍱 | **Catálogo Gourmet** | Exibição visual dos pratos e itens do cardápio com descrições e valores. |
| 🛒 | **Carrinho Interativo** | Adição e remoção dinâmica de itens com atualização de quantidade em tempo real. |
| 💳 | **Fluxo de Checkout** | Página dedicada para revisão final dos itens escolhidos e envio do pedido. |

---

### 🛠️ Tecnologias Utilizadas

* 🟧 **HTML5** — Estruturação semântica das páginas e formulários
* 🟦 **CSS3** — Estilização, temas visuais e regras de responsividade
* 🟨 **JavaScript** — Manipulação da DOM, cálculo de totais e lógica do carrinho
